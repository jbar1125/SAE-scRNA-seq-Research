# Fixed identity-test boundary audit

The plan/generator were committed before outcomes at `7a3c220`.
`provenance.json` records the complete fixed plan, exact source hashes, versions
and working-tree status. `results.jsonl` contains 600 unique records: 100 seeds
crossed with six analyses, retaining all nine hypotheses and design diagnostics.
`summary.json` and `run.log` retain counts, exact within-analysis binomial intervals
and execution output. `manifest.json` hashes the retained raw outputs.

These are simulated downstream scores, with marker matches stipulated and no
trained SAE. Some worlds share draws; paired analyses are not independent trials.
Graded generic severity is a real alternative to equal identity rank locations,
not a false rejection of that statistical null. Complete batch confounding gives
no exchangeable identities, so p=1 is uninformative. Correlated-cell shuffling
violates the population null's unit structure. The separate cluster-mean analysis
uses four independent units per identity and minimum-two-unit eligibility; it
is not the deployed 20-cell procedure or a validated Norman guide-unit analysis.

The experiment leaves the running SAE and inference implementation unchanged.
See [interpretation and results](../../docs/PROGRAM_MODULATION_AUDIT.md) for limits.
